# Beauty Beyond Tears

A magazine-style website for **Beauty Beyond Tears**, a ministry of hope and healing founded by **Pontsho Moselakgomo** — speaker, writer, and author of *Life of a Widow*.

> "We are beautiful souls beyond the tears we cry."

## About

Beauty Beyond Tears is a sanctuary for women walking through grief, loss, and the long road back to themselves. The site reflects the heart of the ministry: to see beauty in dark places, love beyond broken, and pray beyond the tears.

This is a static, frontend-only website — intentionally simple, fast, and easy to maintain. It does not require a backend database.

## Features

- **Editorial magazine layout** with elegant typography and soft, faith-inspired visuals
- **Hero section** centered on the Beauty Beyond Tears logo and brand message
- **Mission & Vision** drawn directly from the ministry's heart
- **Four pillars** of what the ministry offers: counseling, prayer, safe spaces, and community
- **Founder profile** highlighting Pontsho Moselakgomo and her book *Life of a Widow*
- **Field Journal gallery** with photo stories from gatherings and events
- **WhatsApp integration** — every "Talk to Us" and phone link opens a chat with the ministry
- **First-visit scripture welcome** — a random encouraging Bible verse greets each visitor
- **Smooth scroll-reveal animations** and hover interactions
- **Mobile-first responsive design** with reduced-motion support

## Tech Stack

- [TanStack Start](https://tanstack.com/start) — full-stack React framework
- [React 19](https://react.dev/) — UI library
- [TypeScript](https://www.typescriptlang.org/) — type-safe development
- [Tailwind CSS v4](https://tailwindcss.com/) — utility-first styling
- [Vite 7](https://vitejs.dev/) — build tooling

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (recommended) or Node.js
- Git

### Installation

```bash
git clone https://github.com/AmoDevFullStack/beautybeyondtears.git
cd beautybeyondtears
bun install
```

### Run locally

```bash
bun run dev
```

The dev server will start at `http://localhost:8080`.

### Build for production

```bash
bun run build
```

## Design Tokens

The site uses a warm, editorial palette:

- **Paper** — soft cream background
- **Ink** — deep charcoal text
- **Mauve** — primary accent for buttons and highlights
- **Blush / Accent** — secondary warm tones

Fonts: a serif display face for headlines and a clean sans-serif for body text.
